# Aurora TLK Explorer 1.1.0 features

- Edit Neverwinter Nights `.tlk`, text/binary `.2da`, and `.itp` palette files.
- Open multiple documents in tabs from the app, file manager, or drag-and-drop.
- Reuse the existing application window when opening additional associated files.
- Save safely with atomic writes, Save As, unsaved-change protection, and
  bounded undo/redo.
- Search, replace, cut/copy/paste, add, insert, delete, renumber, resize, and
  edit table rows and columns.
- Insert multiple blank TLK or 2DA rows above or below the selection.
- Keep 2DA Index and TLK StrRef columns visible while scrolling horizontally.
- View User StrRef and hexadecimal StrRef representations.
- Use TlkEdit-compatible diff, DTU merge, marking, and overview workflows.
- Choose TLK V3.0 encodings and edit full multiline text entries.
- Use browser-style middle-click autoscroll, tuned mouse-wheel scrolling, and
  accessible dark, light, or system themes.
- Run portably on 64-bit Windows 10/11 and Linux distributions with glibc 2.17
  or newer. KDE Plasma Wayland launches on the output under the pointer.
